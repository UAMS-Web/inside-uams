# Puget Sound

InsideUAMS child theme for the UAMS 2016 theme (`uams-2016`).

Documentation is in the [wiki](https://github.com/UAMS-Web/inside-uams/wiki): a first walkthrough, the reference for the breadcrumbs, header styles and quick links feed, and troubleshooting.

## Requirements

- WordPress 6.8 or later
- PHP 8.2 or later
- The parent theme, [UAMS 2016](https://github.com/UAMS-Web/uams-2016), installed in a folder named `uams-2016`

## Installation

1. Install the parent theme, UAMS 2016.
2. Install this theme from a [release](https://github.com/UAMS-Web/inside-uams/releases) download into its own folder under `wp-content/themes/`.
3. On a multisite network, Network Enable it; then activate it on each site that uses it. The [wiki's walkthrough](https://github.com/UAMS-Web/inside-uams/wiki/Activating-the-theme-on-a-site) shows what changes.
