Puget Sound is the InsideUAMS child theme of the UAMS 2016 theme (`uams-2016`). It keeps the parent's templates and changes three things: the header strip and site title styles, the breadcrumb trail, and an optional quick links feed.

This wiki holds a first walkthrough, the reference for each of those changes, and troubleshooting. The [README](https://github.com/UAMS-Web/inside-uams#readme) keeps the overview, the requirements and installation.

## Getting started

- [Installation (README)](https://github.com/UAMS-Web/inside-uams#installation): install the parent theme, then this one.
- [Activating the theme on a site](Activating-the-theme-on-a-site.md): from an installed theme to a site showing it.
