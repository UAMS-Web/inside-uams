Where the theme is developed, how to report a problem, and where releases are.

- **Repository:** [UAMS-Web/inside-uams](https://github.com/UAMS-Web/inside-uams). Changes go through a pull request to `master`, as [CONTRIBUTING.md](https://github.com/UAMS-Web/inside-uams/blob/master/CONTRIBUTING.md) describes.
- **Report a problem:** [open an issue](https://github.com/UAMS-Web/inside-uams/issues).
- **Releases:** [the releases page](https://github.com/UAMS-Web/inside-uams/releases). The wiki is published from `docs/wiki/` on each release and can be published by hand from the Actions tab.
- **Parent theme:** [UAMS-Web/uams-2016](https://github.com/UAMS-Web/uams-2016).
